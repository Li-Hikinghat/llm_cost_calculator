成本口径

本地综合电费 = Prefill 电费 + Decode 电费，两个阶段暂按同一整机平均功耗计算；不含服务器购置、折旧、闲置功耗、散热、机房、运维和网络成本。GPT5.6 LUNA 官方 API 输入按缓存输入价、输出按输出价估算；DeepSeek V4 Flash 按空闲时段缓存输入价与输出价估算；API 总费用 = 缓存输入费用 + 预计输出 tokens 费用。

所有计算均在本地浏览器完成，不会上传输入数据。GPT5.6 LUNA 官方 API 默认参考价：缓存输入 ¥0.1344/M、输出 ¥8.06/M，均可在页面中修改。DeepSeek V4 Flash 空闲时段参考价：缓存输入 ¥0.05/M、输出 ¥4.50/M。本计算器以官方 API 最低价格参考，价格可能有变动，可自行调整价格。
